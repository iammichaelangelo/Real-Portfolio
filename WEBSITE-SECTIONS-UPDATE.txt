HOW TO ADD ANOTHER WEBSITE
Open data/projects.ts and add another item inside the Website Projects gallerySections array:

{
  title: "Website Name",
  subtitle: "Short website description",
  liveUrl: "https://your-live-website.com",
  liveLabel: "Visit Live Site",
  images: [
    "/images/projects/your-folder/screenshot-1.png",
    "/images/projects/your-folder/screenshot-2.png"
  ]
}

Then place the screenshots inside:
public/images/projects/your-folder/

The Visit Live Site button is displayed only when liveUrl is provided.
