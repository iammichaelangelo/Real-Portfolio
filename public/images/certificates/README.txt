HOW TO ADD CERTIFICATES

1. Put certificate images in this folder. JPG, PNG, WebP, or SVG are supported.
2. Open data/certificates.ts.
3. Add or edit an entry with title, issuer, date, and image path.

Example:
{
  title: "Civil Service Professional",
  issuer: "Civil Service Commission",
  date: "2026",
  image: "/images/certificates/civil-service.jpg",
  credentialUrl: "https://optional-verification-link.com"
}

The gallery automatically creates more rows as you add entries.
